clusteredheatmap documentation
==============================

These documents contain user documentation for the clusteredheatmap library.
This library allows you to create clustered heatmaps (also called cluster maps,
clustergrams, cluster heatmaps, etc.) for your data.
The visualisation is based on plotly.
